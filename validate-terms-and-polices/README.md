# Validar termos e política de privacidade

Instale esta skill junto com create-terms-and-polices. Consulte os [comandos de instalação global e uso](../create-terms-and-polices/README.md).

Dentro desta pasta, o comando local também funciona:

```bash
npx skills add .. --skill create-terms-and-polices validate-terms-and-polices --global --agent codex claude-code --copy
```

## Instalar pelo GitHub, sem clonar

```bash
npx skills add https://github.com/abnerndr/skills --skill create-terms-and-polices validate-terms-and-polices --global --agent codex claude-code --copy
```

Escolha somente os agentes que utiliza. Para outros agentes e instalação por projeto, veja o [guia completo](../create-terms-and-polices/README.md).
